# Hammad Khadim Hussain — Portfolio

Personal portfolio for a senior full stack developer. Built with React and Vite. Content follows the CV: roles at Pixelz360, Cubix, and EvantageSoft, plus skills, projects, and education.

```bash
npm install
npm run dev
```

Open the local URL Vite prints. `npm run build` creates the production site in `dist`. The downloadable CV is `public/Hammad-Khadim-Hussain.pdf`.
